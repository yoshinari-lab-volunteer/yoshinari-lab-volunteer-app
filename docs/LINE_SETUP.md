# LINEログインのセットアップ

LINEアカウントでの会員登録・ログイン、および既存会員とのアカウント連携を有効にする手順です。
**この設定をするまでは、サイト上にLINE関連のボタンは一切表示されません**（環境変数が未設定の間は機能ごと無効）。

## 仕組みの概要

- LINE の「LINEログイン」（OAuth 2.0 / OpenID Connect）で本人確認します。
- 確認できた LINE のユーザーID と、サイトの会員を `lineAccounts` コレクションで紐付けます。
- LINE はメールアドレスを渡さないため、**LINEで新規登録する会員はメールアドレスを持ちません**。
  初回のみ、氏名と電話番号（応募に必須の項目）を入力してもらいます。
- すでにメールで登録済みの会員は、**ログイン後にマイページの「LINE連携」から連携**できます。
  （メールアドレスが同じだからといって自動で紐付けることはしません。他人のLINEで会員情報を乗っ取られる恐れがあるため）

## 1. LINEログインチャネルを作る

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログインする
2. プロバイダーを作成する（すでにある場合は、公式アカウントと**同じプロバイダー**を選ぶ。後述の通知連携で必要）
3. 「LINEログイン」のチャネルを新規作成する（アプリタイプは「ウェブアプリ」）
4. チャネルの基本設定から次の2つを控える
   - **チャネルID**
   - **チャネルシークレット**（他人に見せない。GitHubにも載せない）

## 2. コールバックURLを登録する

LINEログイン設定の「コールバックURL」に、次のURLを登録します（`NEXT_PUBLIC_SITE_URL` と完全に一致させる）。

| 環境 | コールバックURL |
| --- | --- |
| 本番 | `https://（本番のドメイン）/api/auth/line/callback` |
| ローカル開発 | `http://localhost:3000/api/auth/line/callback` |

## 3. チャネルを「公開済み」にする

チャネルが「開発中」のままだと、**そのチャネルの管理者・テスターしかLINEログインできません**。
一般の利用者に使ってもらう前に、必ず「公開」に切り替えてください。

## 4. 環境変数を設定する

Vercel の Environment Variables（ローカルは `.env.local`）に追加し、再デプロイします。

| 変数名 | 値 |
| --- | --- |
| `LINE_CHANNEL_ID` | 控えたチャネルID |
| `LINE_CHANNEL_SECRET` | 控えたチャネルシークレット（`NEXT_PUBLIC_` を付けない） |
| `LINE_BOT_PROMPT` | （任意）`normal` または `aggressive`。次節を参照 |

## 5. 公式アカウントの友だち追加を促す（任意）

LINEログインのときに「公式アカウントを友だち追加する」選択肢を出せます。ログインだけなら不要なので、先にログインの動作確認を済ませてから設定して構いません。

1. LINE Developers コンソールで LINEログインのチャネルを開き、**「チャネル基本設定」タブ → 「リンクされたLINE公式アカウント」の「編集」**で、友だち追加させたい公式アカウントを選んで更新する
2. Vercel に `LINE_BOT_PROMPT=normal` を設定して再デプロイする
   - `normal`：LINEの同意画面の中に友だち追加のオプションが表示される
   - `aggressive`：同意画面のあとに、友だち追加するかを尋ねる別の画面が表示される

### 公式アカウントがまだ無い場合

1. [LINE ビジネスID](https://account.line.biz/) に登録し、表示されるフォームから LINE 公式アカウントを作成する
2. [LINE Official Account Manager](https://manager.line.biz/) で、作成した公式アカウントの「Messaging APIの利用を有効にする」操作を行う
3. このとき**プロバイダーの選択で、LINEログインチャネルと同じプロバイダーを選ぶ**
   （一度選ぶと後から変更できません。LINE Developers コンソールでMessaging APIチャネルを直接作ることはできなくなっています）

### リンクの一覧に公式アカウントが出てこない場合

次の条件を確認してください。
- 公式アカウントの **Messaging API が有効**で、そのMessaging APIチャネルが **LINEログインチャネルと同じプロバイダー**にある
  （別のプロバイダーにあるとリンクできません。公式アカウントを作り直すか、LINEログインチャネルを同じプロバイダーに作り直す必要があります）
- 操作しているLINEアカウントが、LINEログインチャネルの **Admin 権限**（LINE Developers コンソール）と、公式アカウントの **管理者権限**（LINE Official Account Manager）の両方を持っている
- 1つのLINEログインチャネルにリンクできる公式アカウントは1つだけ

## 動作確認のチェックリスト

- [ ] ログイン画面・新規登録画面に緑の「LINEでログイン」「LINEで新規登録」ボタンが出る
- [ ] LINEで新規登録 → 氏名・電話番号を入力 → マイページに入れる（メール確認の案内は出ない）
- [ ] ログアウト後、「LINEでログイン」で同じ会員に戻れる
- [ ] メールで登録済みの会員が、マイページの「LINEと連携する」で連携できる
- [ ] 連携後、「LINEでログイン」でそのメール会員としてログインできる
- [ ] 管理画面のユーザー一覧に、LINE登録の会員が「メール未登録（LINEで登録）」と表示される

## 補足

- **連携の解除**はメールアドレスを持つ会員のみ可能です。LINEで登録した会員は、解除するとログイン手段がなくなるため解除できません。
- 退会（無効化）した会員は、LINEからもログインできません。
- 会員データには LINE のユーザーID（`users/{uid}.lineUserId`）を保存しています。
  同じプロバイダー内の Messaging API チャネルを使えば、このIDを宛先にLINEでの通知（承認のお知らせ等）を送る機能も後から追加できます
  （現状は未実装です）。
